# Arknights: Endfield Gizil Farming Helper

명일방주: 엔드필드 (Arknights: Endfield) 기질 파밍 효율 계산기입니다.
Github Pages를 통해 호스팅되는 단일 페이지 웹 애플리케이션입니다.

## 기능
- **무기 선택**: 보유한 무기를 최대 4개까지 선택하여 최적의 파밍 장소를 찾습니다.
- **필터 및 검색**: 무기 종류(한손검, 양손검 등) 필터링 및 이름 검색 기능을 제공합니다.
- **효율 분석**: 선택한 무기들의 옵션을 분석하여 각 구역별 파밍 효율을 "가능(종결)"과 "불가능"으로 구분해 보여줍니다.
- **데이터 시각화**: 각 무기의 희귀도(6성/5성)에 따른 색상 구분과 직관적인 UI를 제공합니다.

## 사용 방법
1. 웹사이트에 접속합니다.
2. 파밍하고자 하는 무기를 검색하거나 목록에서 선택합니다 (최대 4개).
3. "분석하기" 버튼을 클릭합니다.
4. 하단에 표시되는 추천 지역 결과를 확인합니다.

## 개발 환경
- HTML5, CSS3, Vanilla JavaScript
- VS Code
